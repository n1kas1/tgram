# Поиск корня уравнения f(x)=0 — методы касательных и секущих

Учебный проект (численные методы). Настольное приложение (Windows, PyQt5):
ищет **корень** уравнения `f(x) = 0` методами **касательных (Ньютона)** и
**секущих**. Лимит итераций — 1000.

**Класс функций — линейные комбинации** базиса: `x^k`, `exp(x)`, `ln(x)`,
`sin(x)`, `cos(x)` и константы. Пример: `x^3 - 2*x - 5`.

## Файлы (4 роли)

| Файл | Роль |
|------|------|
| `function_parser.py` | разбор функции из текста + аналитические `f`, `f'` |
| `numerical_methods.py` | `solve_newton`, `solve_secant` (корень уравнения `f(x)=0`) |
| `task_generator.py` | генератор задач на поиск корня с известным ответом |
| `gui.py` | интерфейс PyQt5 + график с точками итераций |

Плюс `main.py`, `requirements.txt`, `example.txt`.

## ВАЖНО (Windows)

Распакуй проект в путь **без кириллицы** (Qt не грузит плагин из путей с
не-латинскими буквами). Например `C:\solver` или `C:\dev\solver`.

⚠️ Если **имя пользователя Windows на кириллице** (напр. `C:\Users\Повелитель`),
то путь `C:\Users\<имя>\Desktop\...` тоже кириллический — этого не исправить
переносом на Рабочий стол. Держи проект и `venv` в корне диска, например
`C:\solver`. Иначе при `pyinstaller` будет ошибка вида
`Qt plugin directory '...PyQt5/Qt5/plugins' does not exist!` (в пути видно
`??????????` вместо имени) — это и есть кириллица в пути.

venv нельзя «переносить» (в нём зашит путь): после копирования проекта в
латинский путь удали старый `venv` и создай новый там же.

## Установка и запуск

```bat
cd <папка solver, путь латиницей>
py -3.12 -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Ядро можно проверить отдельно: `python function_parser.py`,
`python numerical_methods.py`, `python task_generator.py`.

## Сборка .exe (Windows)

Чтобы получить один файл, запускающийся на любом 64-битном Windows без
установленного Python, используется **PyInstaller**. Самый простой путь —
запустить из папки `solver` (путь без кириллицы):

```bat
build.bat
```

Скрипт создаёт venv, ставит зависимости и PyInstaller и собирает
`dist\solver.exe`. Вручную то же самое:

```bat
pip install pyinstaller
pyinstaller --onefile --windowed --name solver main.py
```

Замечания:
- `.exe` для Windows собирается только **на Windows** (PyInstaller не делает
  кросс-сборку под другую ОС).
- `--onefile` кладёт всё в один файл (старт на пару секунд дольше из-за
  распаковки); для более быстрого старта можно убрать флаг — тогда получится
  папка `dist\solver\` с `solver.exe` и библиотеками рядом (её переносят
  целиком).
- Путь без кириллицы важен и для собранного `.exe` (Qt не грузит плагин
  платформы из путей с не-латинскими буквами).

## Теория

- Ищется корень `x*` уравнения `f(x)=0` (где `f` дифференцируема, `f'(x*)≠0`).
- Касательные (Ньютон): `x_{n+1} = x_n - f(x_n) / f'(x_n)`.
- Секущие: `x_{n+1} = x_n - f(x_n)*(x_n - x_{n-1}) / (f(x_n) - f(x_{n-1}))`.
  Метод секущих заменяет производную разностной оценкой
  `f'(x_n) ≈ (f(x_n) - f(x_{n-1})) / (x_n - x_{n-1})` — вторая производная не нужна.
- Когда функцию можно продифференцировать — удобнее касательные; когда нет —
  секущие.
- Останов: `|f(x_{n+1})| ≤ tol` или `|Δx| ≤ tol`; не более 1000 итераций.
